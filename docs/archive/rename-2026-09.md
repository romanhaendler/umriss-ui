# The rename of September 2026 — old name → new name

The effort `english-and-umriss-ui` renamed this workspace from two languages to
one: the npm scope, every package name, the public names, the values behind them
and the wording. These tables recorded what became what, and they stood in
`CONTEXT.md` until the documents were sorted by genre.

They are kept, and they are kept **here**, because a glossary says what a word
means now while these tables say what a word used to be called. They are still
needed: the specs under `.scratch/` speak in the old names, and a reader who
follows one of them lands here.

Nothing below describes the workspace as it is. The live vocabulary is
`CONTEXT.md`; the decision behind the rename is
[ADR-0018](../adr/0018-everything-is-english.md).

## Public names

What crosses out of `@umriss-ui/core` into `@umriss-ui/table`, the demos and any
application. They are listed because they are the one set of names several
branches read at once.

| `schwere` | `verdictWeight` — not `severity`, which belongs to a limit |

The table's own public names follow the same rule and are resolved where they
live: `TabellenAnsicht` → `TableView`, `initialeAnsicht` → `initialView`,
`SortierStufe` → `SortLevel`, `t.ansicht` → `t.view`, `sichtbareSpalten` →
`visibleColumns`, `alsCsv` → `asCsv`, `SpaltenEintrag` → `ColumnEntry`,
`Tabelle` → `Table`, `TabellenStand` → `TableSnapshot`. `Stand` does **not**
become `State` anywhere: that word is the charts' (ADR-0007).

## Values, not only names

A rename that stops at the identifier leaves the library half German, because a
value is read as often as the name that holds it — in the DOM, in a selector, in
a screenshot's file name. These are the sets that moved, each in one commit with
every consumer:

| What | Old | New |
|---|---|---|
| `Place` (public, `data-place`, eight baselines) | `oben` · `rechts` · `unten` · `links` | `top` · `right` · `bottom` · `left` |

| `LimitSet` · `Limit` · `Assessment` fields | `grenzwerte` · `sollwert` · `wert` · `seite` · `stufe` · `urteil` · `grenzwert` · `ueberschreitung` · `abweichung` | `limits` · `target` · `value` · `side` · `severity` · `verdict` · `limit` · `excess` · `deviation` |

| `LifecycleState` · `Transition` · `Priority` | `anstehend-…` · `gegangen-…` · `gekommen` · `quittiert` · `hoch`/`mittel`/`niedrig` | `standing-…` · `cleared-…` · `raised` · `acknowledged` · `high`/`medium`/`low` |

## Four names the table needed

Four names the table needed and this file did not have. **Projection** is the
model's computed output — visible columns, the filtered set, the page — and is
deliberately not a **View**: a view is the part an application keeps, and the two
are different objects. **Return band** avoids "threshold", which is an avoided
word for a **Limit**; it is the dead band an alarm's reading must come back past
before the alarm clears.

| Old | New |
|---|---|
| `TabellenSicht` · `MeldeSicht` | `TableProjection` · `AlarmProjection` |
| `TabellenZustand` | `TableInput` — not `…State` (ADR-0007) |
| `TabellenBezug` | `TableRef` |
| `Rueckfallschwelle` | `ReturnBand` |
