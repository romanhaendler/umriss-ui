# @umriss-ui/alarms API

Generated by the props step (`pnpm --filter @umriss-ui/alarms props`); do not edit. Lists every export, and the props, options and returns of each component and hook, with first sentences only; the full text is `docs/llms-full.md`. What stands under `## Experimental`, or is marked `(experimental)`, may change in a minor release; everything else is the surface a break costs a major for (ADR-0083).

## Components

- AlarmBanner — The worst active, unacknowledged alarm in service on every screen, the count per priority, and one tap to the list or to acknowledge.
- AlarmList — The list of alarms, operable: a table over the rows of `alarmModel`, with priority, lifecycle state and age, the acknowledgement of one alarm or of the selection, and - with `asOf` and `ages` - how old the data is.
- PriorityMark — The mark of an alarm's priority: a filled shape that differs by outline per level, the level's number inside, and a colour from a token per level - so it is told apart in forced colours, in greyscale and by a colour-blind reader.

## Functions

- acknowledge(alarms: readonly Alarm[], ids: Iterable<string>, time: number): Acknowledgement — Acknowledges the named alarms at the named time.
- availabilityAt(alarm: Alarm, asOf: number): Availability — The availability at the as-of time.
- countAcknowledgeable(alarms: readonly Alarm[], ids: Iterable<string>, asOf: number): number — How many of the named alarms an acknowledgement would actually change.
- countInWindow(times: readonly number[], windowMs: number, asOf: number) => number — How many of the points in time lie within the window.
- detectFlood(alarms: readonly Alarm[], rule: FloodRule, asOf: number): Flood | null — Is there a flood in the window before the as-of time?
- disable(alarm: Alarm): Alarm — Takes an alarm out of service ("Out of service" on screen) - from service or from a snooze.
- enable(alarm: Alarm): Alarm — Returns a disabled alarm to service.
- frequencyByType(alarms: readonly Alarm[], windowMs: number, asOf: number): Map<string, number> — Frequency per alarm type within the window.
- hasReturned(band: ReturnBand, value: number) => boolean — Has the value come back far enough for an active alarm to resolve?
- isAcknowledged(state: LifecycleState) => boolean — Whether someone has acknowledged the alarm, active or resolved.
- isActive(state: LifecycleState) => boolean — Whether the condition still holds: active, acknowledged or not.
- isDone(state: LifecycleState) => boolean — Resolved and acknowledged: the only position that leaves the list.
- isHidden(availability: Availability) => boolean — Everything but in service: still in the list, drawn neutrally and counted, never removed.
- lifecycleAt(alarm: Alarm, asOf: number): LifecycleState — The lifecycle at a time: the stored one, except that an alarm whose shelve has ended and which is still active is in alarm and unacknowledged again.
- nextLifecycleState(state: LifecycleState, transition: Transition): LifecycleState — The transition as pure calculation.
- priorityRank(priority: Priority) => number — 0 is the most urgent.
- snooze(alarm: Alarm, until: number, by: string, reason?: string): Alarm — Shelves ("Shelve" on screen) an alarm in service, or snoozes anew what is snoozed.
- unsnooze(alarm: Alarm): Alarm — Ends a shelve before its time ("Unshelve" on screen).

## Constants

- AVAILABILITIES: readonly Availability[] — In service first, then by how near each is to coming back: snoozed (a person's own decision, with an end), suppressed, disabled.
- PRIORITIES: readonly Priority[] — From the most urgent to the last - the order of the scale.

## Types

- Acknowledgement — What `acknowledge` returns: the alarms afterwards, and how many it changed. [alarms, count]
- Alarm — One occurrence of a type. [id, type, lifecycle, raised, resolved, acknowledgedAt, group, sequence, availability, snooze]
- AlarmAnnunciation — What `onAnnunciate` reports: an alarm that was not waiting before now is (with the highest priority among those), or the last waiting alarm is gone. = { kind: "new", priority } | { kind: "cleared" }
- AlarmAvailability — Whether an alarm is in service, and while it is snoozed until when and by whom. = { availability, snooze } | { availability: "snoozed", snooze }
- AlarmBannerProps — Props of `AlarmBanner`; the rest go to its root `<section>`.
- AlarmBase — What every alarm has, whatever its availability: its id, its type, its place in the lifecycle and its moments. [id, type, lifecycle, raised, resolved, acknowledgedAt, group, sequence]
- AlarmColumn — Ids of the columns that are sorted, searched and ordered in. = "type" | "lifecycle" | "availability" | "priority" | "acknowledgement" | "raised" | "age" | "frequency"
- AlarmInput — The input of `alarmModel`: the alarms, their types, the as-of time, and the rules for chatter and floods. [alarms, types, asOf, chatter, flood, keepDone, columns]
- AlarmListProps — The props of `AlarmList`: a div's attributes, the projection to show, and the hooks for selection, acknowledgement and freshness.
- AlarmRow — An alarm with everything the list and the order need to know about it. [id, alarm, type, lifecycle, availability, priority, rank, age, duration, frequency, chatters, inFlood, firstOut]
- AlarmType — The condition that can become true. [id, label, priority, returnBand]
- Availability — Whether an alarm is in front of the people watching the list. = "in-service" | "snoozed" | "suppressed" | "disabled"
- ChatterRule — From when a type counts as chattering. [windowMs, atLeast]
- Flood — A flood that has been detected. [from, to, count, alarms, first]
- FloodRule — From when a set of alarms is a flood. [windowMs, atLeast]
- LifecycleState — One field, four values. = "active-unacknowledged" | "active-acknowledged" | "resolved-unacknowledged" | "resolved-acknowledged"
- Priority — Four levels. = "critical" | "high" | "medium" | "low"
- PriorityMarkProps — Props of `PriorityMark`; the rest go to its root `<span>`.
- ReturnBand — The triggering bound and the return band of an alarm type. [direction, limit, returnTo]
- Snooze — A shelve - the screen's word for a snooze: a person's own, time-limited decision to take an alarm out of the way. [until, by, reason]
- Transition — What can happen to an alarm. = "raised" | "acknowledged" | "resolved"

### AlarmProjection

- flood: Flood | null — The flood that was detected, when a rule was given and it applies.
- rate: number — The alarms raised in the ten minutes before the as-of time, whatever their state: the figure the flood mark names.
- activeUnacknowledged: number — Active and unacknowledged within the filtered set - the number for the polite screen reader.
- unacknowledgedByPriority: Record<Priority, number> — The same alarms as `activeUnacknowledged`, counted per priority.
- hiddenAlarms: number — Hidden within the filtered set: snoozed, suppressed, disabled.
- columns: readonly ModelColumn<AlarmRow, AlarmColumn>[] — The visible columns in their order – the basis for the header row, the column menu and the CSV export.
- filtered: AlarmRow[] — Everything the filter leaves – the basis for figures and the selection.
- visible: AlarmRow[] — Only the current page - with a grouping, the rows among its lines.
- groups?: RowGroup<AlarmRow>[] — With a grouping: the groups, outermost first.
- lines?: Line<AlarmRow>[] — With a grouping: every line of the filtered set.
- visibleLines?: Line<AlarmRow>[] — With a grouping: the lines of the current page, with what it repeats.
- entries?: readonly FlatteningEntry<AlarmRow, RowKey>[] — Tree rows: the flattening - the rows shown, in reading order, with their level and state.
- shown?: AlarmRow[] — Tree rows: every row the flattening shows, before a virtual window.
- roots?: AlarmRow[] — Tree rows: the roots that match or lead to a match - what a footer sums, since a parent already holds its children.
- exported?: readonly FlatteningEntry<AlarmRow, RowKey>[] — Tree rows: every row of the filtered tree in reading order, open or not, path rows included - what the export writes.
- total?: number — Tree rows: how many rows the tree has on every level - what "of 1,204" counts, as the rows the pre-filter admits do for a flat table.
- page: number — The clamped page actually shown.
- pageCount: number
- columnCount: number

### AlarmList

#### props (AlarmListProps)

- view: AlarmProjection — The projection from `alarmModel`.
- selection?: TableSelection<string> — The caller's selection helper; without it there is no bulk acknowledgement.
- onAcknowledge?: (ids: readonly string[]) => void — Gets the ids that are to be acknowledged.
- onSnooze?: (ids: readonly string[], until: number, reason?: string) => void — Gets the ids the operator wants to snooze and the end they chose (`asOf` of the view plus a duration of `snoozeDurations`).

- snoozeReasons?: readonly string[] — The reasons the application offers when shelving, shown as choices above a free-text field for a reason not on the list.
- snoozeDurations?: readonly number[] — The durations on offer, in milliseconds. (default: none - the application names them)
- onUnsnooze?: (ids: readonly string[]) => void — Gets the ids whose snooze the operator wants to end early.
- asOf?: Date | number | null — When the data was true.
- ages?: FreshnessAges — From when the data counts as stale and from when as disconnected.
- density?: "regular" | "compact" — `"regular"` or `"compact"`; compact reduces the row height for very dense views. (default: the density of the `UmrissProvider`, else `"compact"`)
- maxHeight?: string — Height of the list's scroll area, e.g. `"480px"`: a list of hundreds of rows scrolls inside it, under its sticky header, instead of stretching the page.
- hiddenOnly?: boolean — The view of hidden alarms is on.
- onHiddenOnlyChange?: (hiddenOnly: boolean) => void — Offers the view as a switch beside its count.
- freshness?: FreshnessAges — The old name of `ages`. (deprecated)

### PriorityMark

#### props (PriorityMarkProps)

- priority: Priority — The level, as a shape and its number: 1 a diamond, 2 a triangle, 3 a square, 4 a circle.

## Types in full

### Acknowledgement

- alarms: Alarm[]
- count: number — How many alarms the acknowledgement actually changed.

### Alarm

- id: string
- type: string — Id of the alarm type.
- lifecycle: LifecycleState
- raised: number — The moment of coming, in milliseconds.
- resolved?: number — The moment of resolving; while the alarm is active: none.
- acknowledgedAt?: number — The moment of the acknowledgement, as long as unacknowledged: none.
- group?: string — The application's trip or unit: the set of alarms one cause raises.
- sequence?: number — The application's own order, for alarms whose `raised` collide: the lower one is first.
- availability?: Exclude<Availability, "snoozed"> | "snoozed" — Without a statement: in service.
- snooze?: undefined | Snooze — Until when, and by whom.

### AlarmBase

- id: string
- type: string — Id of the alarm type.
- lifecycle: LifecycleState
- raised: number — The moment of coming, in milliseconds.
- resolved?: number — The moment of resolving; while the alarm is active: none.
- acknowledgedAt?: number — The moment of the acknowledgement, as long as unacknowledged: none.
- group?: string — The application's trip or unit: the set of alarms one cause raises.
- sequence?: number — The application's own order, for alarms whose `raised` collide: the lower one is first.

### AlarmInput

- alarms: readonly Alarm[]
- types: readonly AlarmType[] — The catalogue of conditions.
- asOf: Date | number — A `Date` or milliseconds since the epoch.
- chatter?: ChatterRule — Without it `frequency` counts every occurrence up to the as-of time and `chatters` stays false.
- flood?: FloodRule — Without it no flood is detected and nothing is marked.
- keepDone?: boolean — Show the alarms that are done as well (resolved and acknowledged). (default: false)
- columns?: readonly ModelColumn<AlarmRow, AlarmColumn>[] — The columns of the projection; without a statement `ALARM_COLUMNS`. (default: ALARM_COLUMNS)

### AlarmRow

- id: string — Id of the alarm - the key for selection and acknowledgement.
- alarm: Alarm
- type: AlarmType
- lifecycle: LifecycleState — At the as-of time: an alarm back from an ended shelve is unacknowledged here.
- availability: Availability — At the as-of time: an expired snooze is already back in service here.
- priority: Priority
- rank: number — 0 is the most urgent.
- age: number — Since the coming, from the as-of time passed in.
- duration: number — How long the condition was true - until the resolving, otherwise until the as-of time.
- frequency: number — Occurrences of this TYPE within the window; without a chatter rule: all of them up to the as-of time.
- chatters: boolean — The TYPE chatters.
- inFlood: boolean — This alarm belongs to the flood that was detected.
- firstOut: boolean — The first alarm of its group, done ones included.

### AlarmType

- id: string
- label: string
- priority: Priority
- returnBand?: ReturnBand — The dead band, when the type has one.

### ChatterRule

- windowMs: number — Length of the window in milliseconds.
- atLeast: number — From how many occurrences within the window.

### Flood

- from: number — Earliest and latest moment of the alarms involved - so that the interface can say "forty alarms in 82 seconds".
- to: number
- count: number
- alarms: readonly string[] — Ids of the alarms involved.
- first: string — Id of the flood's earliest alarm, by the same rule as first-out.

### FloodRule

- windowMs: number
- atLeast: number — From how many alarms within the window - across all types, because one fault drags nine others with it.

### ReturnBand

- direction: "upper" | "lower" — `upper`: the alarm comes when the value rises above the bound.
- limit?: number — The bound that triggered the alarm.
- returnTo: number — The value the reading must come back past before the alarm resolves.

### Snooze

- until: number — When it ends, in milliseconds.
- by: string — Who snoozed it - a snooze is tracked, not anonymous.
- reason?: string — Why, when the application asked for one.
