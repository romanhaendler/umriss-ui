# @umriss-ui/alarms API

Generated by the props step (`pnpm --filter @umriss-ui/alarms props`); do not edit. First sentences only; the full text is `docs/llms-full.md`.

## Components

- AlarmList — The list of alarms, operable: a table over the rows of `alarmModel`, with priority, lifecycle state and age, the acknowledgement of one alarm or of the selection, and - with `asOf` and `freshness` - how old the data is.

## Functions

- acknowledge — Acknowledges the named alarms at the named time.
- alarmColumns — The columns of the alarm model, labelled from a wording.
- alarmModel — Alarms, types and an as-of time become rows with derived fields and are then handed through the table's pipeline: filter -> sort -> page.
- availabilityAt — The availability at the as-of time.
- countAcknowledgeable — How many of the named alarms an acknowledgement would actually change.
- countInWindow — How many of the points in time lie within the window.
- detectFlood — Is there a flood in the window before the as-of time?
- disable — Disables an alarm - from service or from a snooze.
- enable — Returns a disabled alarm to service.
- frequencyByType — Frequency per alarm type within the window.
- hasReturned — Has the value come back far enough for an active alarm to resolve?
- isAcknowledged — Whether someone has acknowledged the alarm, active or resolved.
- isActive — Whether the condition still holds: active, acknowledged or not.
- isDone — Resolved and acknowledged: the only position that leaves the list.
- isHidden — Everything but in service: still in the list, drawn neutrally and counted, never removed.
- nextLifecycleState — The transition as pure calculation.
- priorityRank — 0 is the most urgent.
- snooze — Snoozes an alarm in service, or snoozes anew what is snoozed.
- unsnooze — Ends a snooze before its time.

## Constants

- ALARM_COLUMNS — The columns with the default labels - for callers without a wording.
- AVAILABILITIES — In service first, then by how near each is to coming back: snoozed (a person's own decision, with an end), suppressed, disabled.
- DEFAULT_ORDER — In service before hidden, then priority, then acknowledgement, then time - the worst first, not the newest.
- PRIORITIES — From the most urgent to the last - the order of the scale.

## Props

### AlarmList

#### props (AlarmListProps)

- view: AlarmProjection — The projection from `alarmModel`.
- selection?: TableSelection<string> — The caller's selection helper; without it there is no bulk acknowledgement.
- onAcknowledge?: (ids: readonly string[]) => void — Gets the ids that are to be acknowledged.
- onSnooze?: (ids: readonly string[], until: number, reason?: string) => void — Gets the ids the operator wants to snooze and the end they chose (`asOf` of the view plus a duration of `snoozeDurations`).
- snoozeReason?: "optional" | "required" — Asks for a reason when snoozing: "Snooze" then opens a small panel with the durations and a field for the reason, and its button reports.
- snoozeDurations?: readonly number[] — The durations on offer, in milliseconds. (default: no default)
- onUnsnooze?: (ids: readonly string[]) => void — Gets the ids whose snooze the operator wants to end early.
- asOf?: Date | number | null — When the data was true.
- freshness?: FreshnessAges — From when the data counts as stale and from when as disconnected.
- density?: "regular" | "compact" — "compact" reduces the row height for very dense views. (default: the density of the `UmrissProvider`, else `"compact"`)
- hiddenOnly?: boolean — The view of hidden alarms is on.
- onHiddenOnlyChange?: (hiddenOnly: boolean) => void — Offers the view as a switch beside its count.
