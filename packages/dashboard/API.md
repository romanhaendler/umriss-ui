# @umriss-ui/dashboard API

Generated by the props step (`pnpm --filter @umriss-ui/dashboard props`); do not edit. First sentences only; the full text is `docs/llms-full.md`.

## Components

- HeadingType — The built-in heading widget type, to put inside `Dashboard` when the application wants readers to divide their dashboard: one size, `full`, one row, its text as its options, drawn as a title without a card.
- WidgetType — Declares one widget type inside a `Dashboard`.

## Hooks

- useDashboard — Declares a dashboard: hands back `Dashboard`, `WidgetType`, the view in view, `setView` and the editing actions.

## Types

- DashboardOptions — What `useDashboard` takes. [defaultView, initialView, allowEdit, onViewChange, onDraftChange]
- DashboardParts — What `useDashboard` hands back. [Dashboard, WidgetType, view, setView, editing, edit, done, catalogue, cancel, undo, redo, reset]
- DashboardProps — The props of `Dashboard`.
- DashboardView — The arrangement of a dashboard: which widgets, in what order, at which sizes, with which options. [widgets]
- DashboardWidget — One widget in a view. [id, type, size, options]
- HeadingOptions — The options of the heading widget type. [text]
- SizeSpan — The room a size takes on the twelve columns, in columns and rows. [columns, rows]
- WidgetContent — What a widget's content is told. [size, options]
- WidgetFormProps — What a type's form is given.
- WidgetSize — The closed set of names a widget's size comes from.
- WidgetTypeProps — The props of `WidgetType`.

## Props

### WidgetType

#### props (WidgetTypeProps)

- name: string — The name a view refers to this type by.
- label: string — The type's name for a reader, and the title of its frame unless `title` says otherwise.
- sentence: string — One sentence on what the type shows.
- sizes: Partial<Record<WidgetSize, SizeSpan>> — The sizes the type offers, each with the columns (of twelve) and rows it takes.
- start: WidgetSize — The size a new widget of this type starts at.
- defaultOptions: Options — The options a new widget starts with.
- title?: (options: NoInfer<Options>) => string — The title of a frame as a function of its options; the `label` without it.
- form?: (props: WidgetFormProps<NoInfer<Options>>) => ReactNode — The form for the options, opened from the widget's menu.
- children: (content: WidgetContent<NoInfer<Options>>) => ReactNode — The content, as a function of the size and the options.

## Options and returns

### useDashboard

#### options (DashboardOptions)

- defaultView: DashboardView — The arrangement the application gives a reader who has none of their own.
- initialView?: DashboardView — The reader's kept arrangement, read once when the hook first runs; a different value on a later render is ignored, as React ignores a changed `defaultValue`. (default: the `defaultView`)
- allowEdit?: boolean — Whether the reader may edit. (default: true)
- onViewChange?: (view: DashboardView) => void — Called once per "Done" that changed something, with the whole arrangement.
- onDraftChange?: (open: boolean) => void — Called with `true` when a draft opens and with `false` when it closes - to warn before navigation.

#### returns (DashboardParts)

- Dashboard: (props: DashboardProps) => ReactNode — The dashboard.
- WidgetType: typeof WidgetType — Declares a widget type inside `Dashboard`.
- view: DashboardView — The arrangement in view: the draft while the mode is on.
- setView: (view: DashboardView) => void — Goes to a whole arrangement.
- editing: boolean — Whether the editing mode is on.
- edit: () => void — Enters the editing mode.
- done: () => void — Leaves the mode, keeps the changes and reports them once if there are any.
- catalogue: () => void — Opens the catalogue.
- cancel: () => void — Leaves the mode and puts the arrangement back as it was before `edit`.
- undo: () => void — Goes one step back in the draft.
- redo: () => void — Goes one step forward again.
- reset: () => void — Steps to the `defaultView`; `undo` brings the arrangement back.
