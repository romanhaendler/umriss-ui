# @umriss-ui/charts API

Generated by the props step (`pnpm --filter @umriss-ui/charts props`); do not edit. First sentences only; the full text is `docs/llms-full.md`.

## Components

- ControlChart — A control chart inside a `Chart`: the values as a line, the control limits and zones computed from them, and the points that break a rule marked.
- DataTable — The chart's values as a table, on demand: a key - in the legend where there is one - opens a table of what the chart shows, one column per visible series, in the tooltip's format.
- Legend — The legend of a chart: one entry per series, or per state of a state band.
- LimitBand — A limit drawn as a band between two values of an axis - a tolerance or a zone.
- LimitLine — A limit drawn as a line across the plot at one value of an axis - a specification limit, or with `role` a control limit.
- Tooltip — Turns on the pointer's interaction with a chart: crosshair, hover markers and the tooltip, built in or from `render`.

## Hooks

- useChart — A chart over your rows: the parts it returns are typed at your row, so that a field name in `value` is checked by the compiler.

## Functions

- assess — What the value is, given the limit set.
- bin — Counts values into bins of equal width.
- breaks — The breaks in working time that lie within the extent [from, to] - what the axis must mark, in domain units.
- calendarFrom — Calendar from an input - a built calendar is passed straight through, a raw list is built once and remembered.
- controlLimits — Centre line and control limits.
- inDoubledHour — Does the clock show this instant's time twice?
- invalidateTheme — Explicit invalidation: devalue the cache, every living chart reads anew and redraws.
- localOffset — The local offset at an instant, as the shift of a grid that is to lie on local time: `wallClock = offset + k · step`.
- pareto — Sorts descending, accumulates, collects the tail and finds the cutoff crossing.
- removedIntervals — The removed spans between the working intervals, for the mark in the axis band.
- resolveColours — Any number of CSS colours - a token, `light-dark(…)`, `var(--…)`, a literal - resolved to values a canvas can draw, in the scheme that applies at `root`.
- subscribeTheme — Subscribe to theme invalidations - a switch of `color-scheme` on the document, the system's preference, or `invalidateTheme()`.
- timeStep — Step for tick candidates in wall clock time, at an intended count.
- toWallClock — Working time → wall clock time; outside [0, total] there is none.
- toWorkingTimeClamped — Wall clock time → working time, but without NaN: whatever lies in removed time falls onto the seam that this span collapses onto anyway; whatever lies before the first or after the last interval onto 0 or onto the whole working time respectively.
- verdictWeight — How heavily a verdict weighs, as a number - for sorting and comparing, as when a matrix is to bring its worst cell to the top.
- violatedIndices — All violated indices, ascending and free of duplicates - the scatter drawn beside the line.
- violations — The rules switched on, each with its indices.
- workingCalendar — Builds a calendar: sorts, merges overlapping and abutting intervals and throws away empty, reversed and non-finite ones.
- workingTimeTicks — Ticks for a working time axis, from an extent in WALL CLOCK TIME.
- zones — The faintly drawn zone lines.

## Props

### ControlChart

#### props (ControlChartProps)

- value: Value<T> — The values of the chart - a number field of its `data`'s rows or a function of them.
- data: readonly T[] — Required: the limits arise out of these values, not out of what happens to be visible.
- origin: ControlLimitOrigin — Given, or from a named reference window - never tacitly from everything on the screen ([ADR-0008](https://github.com/romanhaendler/umriss-ui/blob/main/docs/adr/0008-control-limits-are-not-specification-limits.md)).
- xAxisId?: string — Binding to an x axis. (default: "x")
- yAxisId?: string — Binding to a y axis. (default: "y")
- name?: string — The name in legend and tooltip. (default: "Series n", after its place in the chart)
- format?: ValueFormat — The value as the tooltip writes it - on the line and on the violations., as a function or `NumberOptions`. (default: the y axis' `tickFormat`, else the built-in number format)
- color?: string — Any CSS colour value. (default: the palette's `--uc-series-N`)
- tone?: "ok" | "warning" | "alarm" — A role instead of a colour value for the line; the theme resolves it.
- rules?: Partial<RuleOptions> — Switchable one by one; run lengths are parameters.
- zoneLines?: boolean — The faint zone lines at one and two sigma. (default: true)
- labelUpper?: string — Label of the upper control limit in the axis band. (default: no label)
- labelLower?: string — The same for the lower control limit. (default: no label)
- violationName?: string — Name of the scatter of violations in the legend and the tooltip. (default: "Series n", after its place in the chart)
- onViolations?: (found: readonly Violation[]) => void — The violations as data - they can be listed beside the chart as well as marked on it.

### Legend

#### props (LegendProps)

- placement?: "top" | "bottom" | "left" | "right" — Which side of the plot area the legend stands on. (default: "top")

### LimitBand

#### props (LimitBandProps)

- from: number | Date — Lower edge of the band, in domain units of its axis; along a time axis an instant, in milliseconds or as a `Date`.
- to: number | Date — Upper edge, in domain units of its axis.
- axisId?: string — Axis on which the value lies. (default: the first axis of the orientation)
- orientation?: "x" | "y" — Whether the value lies on the x or on the y axis - a limit is nearly always a value and not a moment. (default: "y")
- severity?: Severity — Two severities, not five: five urgencies are five colours, and five colours on a dense screen are noise. (default: "warning")
- label?: string — What the value means.
- color?: string — Any CSS colour value, in place of the one the severity yields.
- inExtent?: boolean — Whether the value widens the axis extent, so that the limit is certainly visible. (default: true)
- role?: LimitRole — A chosen specification limit or a calculated control limit. (default: "specification")

### LimitLine

#### props (LimitLineProps)

- orientation?: "x" | "y" — Whether the value lies on the x or on the y axis - a limit is nearly always a value and not a moment. (default: "y")
- severity?: Severity — Two severities, not five: five urgencies are five colours, and five colours on a dense screen are noise. (default: "alarm")
- label?: string — What the value means.
- color?: string — Any CSS colour value, in place of the one the severity yields.
- inExtent?: boolean — Whether the value widens the axis extent, so that the limit is certainly visible. (default: true)
- role?: LimitRole — A chosen specification limit or a calculated control limit. (default: "specification")

### Tooltip

#### props (TooltipProps)

- mode?: "x" | "nearest" — "x": every series at the x position; "nearest": only the nearest point. (default: "x")
- limits?: boolean — Adds a row for every labelled `LimitLine` and `LimitBand` on the hit's y axis - its label and value in that axis' format - to the built-in tooltip, and the same to what a key reads out. (default: false)
- render?: (hit: TooltipHit<T>) => ReactNode — Render prop for content of one's own. (default: the built-in tooltip)

## Options and returns

### useChart

#### options (ChartOptions)

- initialView?: ChartView — The view to start from, read once when the hook first runs; a different value on a later render is ignored, as React ignores a changed `defaultValue`.
- onViewChange?: (view: ChartView) => void — Every change the reader makes, once, always the whole view - the one to keep, or to hand another chart's `setView`.
- onSelect?: (hit: TooltipHit<Z>) => void — The reader chose a point: a click on a hit (a tap too), or Enter on the Active point - the same hit the tooltip's `render` receives.
- onRange?: (range: ChartRange<V>) => void — The reader marked a stretch of an x axis: Alt with a drag where the chart zooms, a plain drag where it does not.

#### returns (ChartParts)

- Chart: (props: ChartProps) => ReactNode — The chart over the hook's rows.
- XAxis: <T = Z>(props: XAxisProps<T>) => null — An x axis reads the rows of every series bound to it: the hook's, or with `<XAxis<Row>>` those the series bring as their own `data`.
- YAxis: (props: YAxisProps) => null
- Line: <T = Z>(props: LineProps<T>) => null
- Area: <T = Z>(props: AreaProps<T>) => null
- Bar: <T = Z>(props: BarProps<T>) => null
- Scatter: <T = Z>(props: ScatterProps<T>) => null
- StateBand: <T = Z>(props: StateBandProps<T> & OneLane) => null
- Matrix: <T = Z>(props: MatrixProps<T>) => null
- BoxPlot: <T = Z>(props: BoxPlotProps<T>) => null
- view: ChartView — How the reader is looking at the chart.
- domains: AxisSpans — The span each zoomable x axis shows, by axis `id`; an axis absent shows its own `domain`.
- setView: (view: ChartView) => void — Goes to a whole view; what it leaves out is shown whole again.
- setDomain: (axisId: string, span: readonly [number, number] | null) => void — Puts a span in view on a zoomable x axis - a lone one is `"x"`; `null` shows the axis' own `domain` again.
- hidden: readonly string[] — The hidden series, by `name`.
- toggleSeries: (name: string) => void — Hides the series `name`, or shows it where it is hidden - as a click on its legend entry does.
- showOnly: (name: string) => void — Hides every series but `name`; all are shown where none carries it.
- showAllSeries: () => void — Shows every series again.
- toPng: () => Promise<Blob> — A PNG of the chart as it stands: the plot with its grid, series and limits, the axes with ticks, labels and titles, and the legend, on the chart's own ground in the colour scheme in use, at the chart's size on screen and at least twice its CSS pixels.
